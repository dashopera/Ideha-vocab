## 一、项目定位

给米米做的**看图拼写背单词工具**。核心学习闭环：

**只看图 → 心里想词 → 点图 → 按字母数出下划线 → 输入 → 自动判定 → 拼对了才给释义和例句**

设计原则：
- **英文环境**：释义、例句全英文，不出现中文。
- **单文件成品**：15 张插画以 base64 内嵌，断网可用，可直接丢进手机浏览器。
- **数据源唯一**：一切从 `vocab-builder/` 生成，成品 HTML 永远可重建，不是手改的。

## 五、成品功能（4 个模块）

**1. Cards（主学习闭环）**
- 只显示插画，不给单词；气泡提示「👆 Tap the picture」。
- 点图 → 图片缩小，出现下划线格子（数量 = 字母数，连字符 `-` 单独显示为短线且不计入输入）。
- 边打边填格，输满自动判定；回车可提前判定。
- 拼对 → 绿色 ✓ → 0.7 秒后进入结果页，自动朗读单词。
- 拼错 → 红色抖动 → 显示正确拼写 → 2.2 秒后清空重拼一次。
- `Reveal answer` → 直接看答案（标红），2.6 秒后转结果页。
- 结果页：词性标签、单词、音标、英文释义、用法提示、例句；单词和例句各有独立朗读按钮。
- `🔁 Not yet` 跳过 / `✓ Got it` 标记掌握（只在结果页可用）。
- Prev / Shuffle / Next 导航；全部掌握后出现完成页。

**2. Quiz（反向测验）**
- 给英文释义，四选一选单词，**无图**。
- 实时计分（第几题 / 正确 / 错过），答错停留更久（2.8s vs 1.5s）并朗读。
- 结束按正确率给反馈（≥90 🏆 / ≥70 👏 / 其余 💪），列出所有错词及释义。

**3. List（词表）**
- 一屏看完全部单词：缩略图 + 单词 + 音标 + 释义，点任意一行朗读。

**4. 发音设置**
- 自动挑选**女声**（按 natural/neural/online/samantha/karen 等关键词打分排序）。
- 可调 voice / rate（默认 0.88）/ pitch（默认 1.08）。
- 音源三档：Auto（本地音质够好就用本地，否则走在线）/ Device only / Online human voice（有道词典 TTS，需联网）。
- 选择记忆在 localStorage。

**进度**：按单元独立存 localStorage（key = `vocab_done_<UnitId>`），换单元不丢。

## 六、账号门禁与管理后台（v1.1）

### 6.1 它是什么，不是什么

> **这是门禁（door lock），不是认证（authentication）。**

本应用没有服务器，所有数据只存在这台设备的浏览器 localStorage 里。因此：

- ✅ 能做到：多人共用一台设备时，各自进度互相隔离、互不可见
- ❌ 做不到：阻止懂浏览器控制台的人绕过登录
- ❌ 做不到：跨设备同步（除非用导入 / 导出）

**结论：不要用它保护任何敏感信息。** 它的价值是「分清楚这是谁的进度」，不是「防人」。

### 6.2 首次使用

打开后是创建管理员的界面 —— **第一个账号自动成为管理员**。之后在管理后台可添加家人账号（最多 2–5 人，各自独立进度）。

### 6.3 密码怎么存的

- 每个账号有独立随机 salt
- 存储的是 `SHA-256(salt + '|' + 密码)`，**不存明文**
- 哈希存在 localStorage，**可被离线暴力破解** → 别用重要密码

> 实现细节：便携版是 `file://` 双击打开，`crypto.subtle` 在非安全上下文不可用，
> 所以用纯 JS 实现的 SHA-256。已用 Node 对比标准库验证 9 个用例（含 UTF-8 中文与 55/56/64 字节边界）全部一致。

### 6.4 管理后台（仅 admin 可见）

| 功能 | 说明 |
|---|---|
| 用户账号 | 新增 / 删除成员、重置密码、切换 admin / learner 角色 |
| 词表管理 | 在线增删改单词、新增单元、还原内置词表 |
| 进度统计 | 按人 × 单元显示掌握进度（**仅本机数据**） |
| 导出 / 导入 | JSON 备份与恢复，这是跨设备同步的**唯一通道** |
| 清空数据 | 删除本机全部账号、词表改动与进度 |

**词表改动的存储策略**：localStorage 有 5 MB 上限，而图片 base64 有 580 KB，
所以覆盖层**只存文字、剥离图片**，加载时再按单词名从内置数据回填。
管理员新添加的词暂无插图，需在下一次正式构建时补图。

### 6.5 忘记密码怎么办

没有服务器可以重置。只有两条路：

1. **导入之前导出的备份** —— 门禁页底部有「导入备份 / 忘记密码」，**无需登录即可导入**
2. 清空浏览器数据重来 —— 会丢失全部进度

**所以请定期导出备份。**

| `mmv_session` | 当前登录会话 |

## 九、数据规范

`units/TextN.json` 结构：

```json
{
  "id": "Text1",
  "title": "Text 1",
  "note": "来源说明",
  "words": [ { "w": "...", "pos": "...", "ph": "...", "def": "...", "note": "...", "ex": "...", "prompt": "..." } ]
}
```

| 字段 | 含义 | 约束 |
|---|---|---|
| `id` | 单元 ID | 必须与图片目录名一致（如 `Text1` ↔ `images/Text1/`） |
| `title` | 显示名 | 如 `Text 1` |
| `w` | 单词 | 小写；可含连字符（如 `self-esteem`） |
| `pos` | 词性 | noun / verb / adjective / adverb |
| `ph` | 国际音标 | 带斜杠 |
| `def` | **英文**释义 | 不用中文 |
| `note` | 搭配、易混词、构词提示 | 英文 |
| `ex` | 英文例句 | 英文 |
| `prompt` | 画图描述 | 便于重画 |

**图片匹配规则**：文件名 `NN_slug.png`，`slug` = 单词小写且 `-`、空格、`/` 全部替换为 `_`。例：`self-esteem` → `14_self_esteem.png`。匹配不上时构建会打印 `missing images: xxx`，该词图片留空（卡片会缺图但功能不崩）。

## 十一、已踩过的坑（务必遵守）

1. **图片生成不能并行**：并行会写同名文件互相覆盖（曾 5 张只剩 2 张，白花积分）。必须一次一张，拿到路径立刻改名存档。
2. **`output_dir` 参数无效**：图会落到默认目录，所以改名这一步不能省。
3. **原图不能丢**：`build.py` 依赖 `images/TextN/*.png`。成品 HTML 被覆盖后，没有原图就重建不出来。
4. **单元间互不干扰**：加新单元只新增文件，绝不修改已有 `TextN.json`。
5. **构建缺 Pillow 会直接报错**：用第三节的 venv python，别用裸 `python3`。
6. **预览服务会污染成品 HTML**（踩过三次）：本机预览打开 HTML 时会往源文件注入 `data-page-node-id`（约 4 KB / 79 处）。曾两次误把污染版推上 GitHub。
   **根治方案**：`vocab-builder/sanitize.py` + `.git/hooks/pre-commit`，提交时自动剔除并校验。跑 `sanitize.py` 即可随时修复，脚本幂等。
7. **诊断网络连通性别只用 curl**：环境有 HTTP 代理 `127.0.0.1:59275` 会挡 HTTPS，curl 超时≠网络不通。曾据此误判"连不上 GitHub"，实际 `nc -z github.com 22` 通、SSH 握手成功。测量 TCP 用 `nc`，测 curl 加 `--noproxy '*'`。
