## 五、成品功能（4 个模块）

**1. Cards（主学习闭环）**
- 只显示插画，不给单词；气泡提示「👆 Tap the picture」。
- 点图 → 图片缩小，出现下划线格子（数量 = 字母数，连字符 `-` 单独显示为短线且不计入输入）。
- 边打边填格，输满自动判定；回车可提前判定。
- 拼对 → 绿色 ✓ → 0.7 秒后进入结果页，自动朗读单词。
- 拼错 → 红色抖动 → 显示正确拼写 → 2.2 秒后清空重拼一次。
- `Reveal answer` → 直接看答案（标红），2.6 秒后转结果页。
- 结果页：词性标签、单词、音标、英文释义、用法提示、例句；单词和例句各有独立朗读按钮。
- `🔁 Not yet` 跳过 / `✓ Got it` 标记掌握（只在结果页可用）。
- Prev / Shuffle / Next 导航；全部掌握后出现完成页。

**2. Quiz（反向测验）**
- 给英文释义，四选一选单词，**无图**。
- 实时计分（第几题 / 正确 / 错过），答错停留更久（2.8s vs 1.5s）并朗读。
- 结束按正确率给反馈（≥90 🏆 / ≥70 👏 / 其余 💪），列出所有错词及释义。

**3. List（词表）**
- 一屏看完全部单词：缩略图 + 单词 + 音标 + 释义，点任意一行朗读。

**4. 发音设置**
- 自动挑选**女声**（按 natural/neural/online/samantha/karen 等关键词打分排序）。
- 可调 voice / rate（默认 0.88）/ pitch（默认 1.08）。
- 音源三档：Auto（本地音质够好就用本地，否则走在线）/ Device only / Online human voice（有道词典 TTS，需联网）。
- 选择记忆在 localStorage。

**进度**：按单元独立存 localStorage（key = `vocab_done_<UnitId>`），换单元不丢。

## 六、工作流程 A：新增单元（最常用）

1. **提供词表**：截图、照片或纯文本单词串均可。
2. **确认清单**：列出识别出的单词，有疑问的标出来让你过目。
3. **报价确认**：约 5–10 积分/词，先说数字再动手。
4. **生成插画**：每词一张同风格水彩插画（柔和奶油底 + 鼠尾草绿），画面直接暗示词义。
5. **写入单元**：新词成为 `Text 2`（自动递增），**老单元一个字不动**。
6. **构建 + 自检 → 交付**。

> 单元号自动递增：Text 2 → Text 3 → …… 每个单元独立记录掌握进度。

## 八、数据规范

`units/TextN.json` 结构：

```json
{
  "id": "Text1",
  "title": "Text 1",
  "note": "来源说明",
  "words": [ { "w": "...", "pos": "...", "ph": "...", "def": "...", "note": "...", "ex": "...", "prompt": "..." } ]
}
```

| 字段 | 含义 | 约束 |
|---|---|---|
| `id` | 单元 ID | 必须与图片目录名一致（如 `Text1` ↔ `images/Text1/`） |
| `title` | 显示名 | 如 `Text 1` |
| `w` | 单词 | 小写；可含连字符（如 `self-esteem`） |
| `pos` | 词性 | noun / verb / adjective / adverb |
| `ph` | 国际音标 | 带斜杠 |
| `def` | **英文**释义 | 不用中文 |
| `note` | 搭配、易混词、构词提示 | 英文 |
| `ex` | 英文例句 | 英文 |
| `prompt` | 画图描述 | 便于重画 |

**图片匹配规则**：文件名 `NN_slug.png`，`slug` = 单词小写且 `-`、空格、`/` 全部替换为 `_`。例：`self-esteem` → `14_self_esteem.png`。匹配不上时构建会打印 `missing images: xxx`，该词图片留空（卡片会缺图但功能不崩）。

## 十、已踩过的坑（务必遵守）

1. **图片生成不能并行**：并行会写同名文件互相覆盖（曾 5 张只剩 2 张，白花积分）。必须一次一张，拿到路径立刻改名存档。
2. **`output_dir` 参数无效**：图会落到默认目录，所以改名这一步不能省。
3. **原图不能丢**：`build.py` 依赖 `images/TextN/*.png`。成品 HTML 被覆盖后，没有原图就重建不出来。
4. **单元间互不干扰**：加新单元只新增文件，绝不修改已有 `TextN.json`。
5. **构建缺 Pillow 会直接报错**：用第三节的 venv python，别用裸 `python3`。
