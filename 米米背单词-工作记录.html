一、项目概览

是什么：给米米做的看图拼写背单词工具，单文件 HTML 应用。

核心学习闭环：

只看插画（不给单词）→ 心里想词 → 点图片 → 按字母数出现下划线
→ 输入拼写 → 自动判定 → 拼对了才显示英文释义与例句

设计原则：

  • 纯英文环境 —— 释义、例句一律英文，界面不出现中文
  • 单文件交付 —— 插画 base64 内嵌，离线可用
  • 单一数据源 —— 一切从 vocab-builder/ 生成，成品可随时重建

当前规模：1 个单元（Text 1），15 个单词，15 张插画。

五、产品功能

1. Cards —— 主学习闭环

  • 仅显示插画；点图后缩小并出现下划线格子（数量 = 字母数；连字符单独显示且不计入输入）
  • 边打边填格，输满自动判定；回车可提前判定
  • 拼对 → 绿色 ✓ → 0.7 秒后进入结果页并自动朗读
  • 拼错 → 红色抖动 → 显示正确拼写 → 2.2 秒后清空重拼
  • Reveal answer 直接看答案（标红）
  • 结果页：词性、单词、音标、英文释义、用法提示、例句，单词与例句各有独立朗读按钮
  • 导航：Prev / Shuffle / Next；全部掌握后显示完成页

2. Quiz —— 反向测验

  • 给英文释义四选一，无图
  • 实时计分；答错停留更久（2.8s vs 1.5s）并朗读
  • 结束按正确率反馈（≥90 🏆 / ≥70 👏 / 其余 💪），列出全部错词及释义

3. List —— 词表

  • 一屏看完全部单词：缩略图 + 单词 + 音标 + 释义，点任意一行朗读

4. 发音设置

  • 自动优选女声（按 natural/neural/online/samantha/karen 等关键词打分）
  • 可调 voice / rate（默认 0.88）/ pitch（默认 1.08）
  • 音源三档：Auto / Device only / Online human voice（有道 TTS，需联网）

进度存储：按单元独立存 localStorage（key = vocab_done_<UnitId>），换单元不丢，设备间不互通。

6.2 已踩过的坑

1. zip 中文文件名编码 —— 包内中文名为 cp437 编码，需用 filename.encode('cp437').decode('utf-8') 还原，直接 unzip 会乱码。 2. 图片生成不能并行 —— 并行会写同名文件互相覆盖（曾 5 张只剩 2 张，白花积分）。必须一次一张，拿到立刻改名。 3. 图片生成 output_dir 参数无效 —— 图落默认目录，改名步骤不能省。 4. 原图 PNG 不能丢 —— 成品被覆盖后没有原图就重建不出来。 5. WorkBuddy 内置发布不可靠 —— 见 6.3。 6. 预览服务会污染 HTML —— 预览便携版时被注入 4 KB 的 data-page-node-id 属性。交付前必须校验 MD5。 7. pip 在沙箱内装不上包 —— 改用标准库实现（COS 签名脚本即如此）。
